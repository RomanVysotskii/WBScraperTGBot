# 🤖 Wildberries Parser Telegram Bot

Асинхронный Telegram-бот для парсинга, фильтрации и пагинации поисковой выдачи Wildberries. Проект спроектирован с упором на отказоустойчивость, защиту от блокировок (антифрод) и эффективное управление ресурсами сервера.

**Стек технологий:** `Python 3.11+`, `Aiogram 3.x`, `Playwright`, `Playwright-Stealth`, `Asyncio`, `Aiohttp`

---

## 🚀 Ключевые фичи и архитектурные решения

* 🛡️ **Обход антифрод-систем:** Инициализация браузера Chromium завернута в кастомный асинхронный контекстный менеджер `playwright-stealth`. Сигнатуры автоматизации переопределяются до создания страниц, что полностью нивелирует детект со стороны Wildberries.
* ⚡ **In-Memory Кэширование данных:** Результаты тяжелого парсинга сохраняются в оперативной памяти в разрезе `user_id:sort_type`. Переключение страниц пагинации и смена сортировки происходят мгновенно за счет математического расчета срезов списка без повторных HTTP-запросов.
* 🎛️ **Умная инлайн-клавиатура:** Реализована динамическая генерация кнопок сортировки. Текущий активный фильтр автоматически исключается из меню, разгружая интерфейс для пользователя.
* 🔌 **Изоляция окружения и поддержка прокси:** Полная поддержка динамических прокси (HTTP/SOCKS5) через переменные среды. Если прокси не заданы, бот автоматически переключается на прямые соединения, что делает код универсальным для локальной разработки и деплоя.

## 📊 Схема движения данных

```graph TD
    User -->|"/search товар"| TG[Telegram Bot]
    TG -->|Проверка кэша| Cache{Есть в кэше?}
    Cache -->|Да, мгновенно| Reply[Срез списка товаров]
    Cache -->|Нет, тяжелый запрос| PW[Playwright + Stealth Context]
    PW -->|Имитация скролла| WB[Wildberries]
    WB -->|Парсинг ~80 карточек| TG
    TG -->|Запись в WB_CACHE| Cache
    Reply -->|Вывод 10 товаров + кнопки| User
```
